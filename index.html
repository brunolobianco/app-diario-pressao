    Lembretes

    Leitura automática da foto opcional

    Com uma chave da API da Anthropic, o app lê os números do visor sozinho. Cada leitura custa uma fração de centavo na sua conta. A chave fica guardada só neste aparelho e é enviada apenas para api.anthropic.com.

    Avançado

    Crie a chave em console.anthropic.com → API Keys. Não compartilhe sua chave com outras pessoas.

    Cópia de segurança

    Os dados ficam só neste aparelho e neste navegador. Faça uma cópia de vez em quando, principalmente antes de trocar de celular ou limpar o navegador.

    Apagar dados

    Remove todas as medições e fotos da pessoa selecionada neste aparelho.

    Classificação pela Diretriz Brasileira de Hipertensão Arterial (2020), feita para medidas de consultório. Em medições caseiras, médias a partir de 130/80 mmHg já merecem conversa com o médico. A leitura automática da foto pode errar: confira os números antes de salvar. Este app não substitui avaliação médica.
